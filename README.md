One word, and nothing else: the single word grandma would text about AI.

Grandma spells by ear. "Artificial" is pronounced art-uh-FISH-uhl, so when she texts about artificial intelligence she writes what she hears: **artifishal**. A real typo she would actually make, naming the A of AI itself, with a fish in the middle that makes the joke land with no caption.

## Run it

```sh
python3 -P -s main.py
```

The program writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it. Stdlib only, deterministic, no input, no network.
